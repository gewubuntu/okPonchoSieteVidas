# Poncho character reference

`reference.jpg` is the user's reference illustration of Poncho (512 x 512, orange background). It is the source of truth for Poncho's look. Do not edit or overwrite it.

The design notes derived from it are in `docs/GDD.md`: GDD-ART-02 (character), GDD-ART-03 (palette), GDD-ART-04 (animations), GDD-MOV-06 (size and hitbox). The "PB" marks stand for Poncho on Base (GDD-VIS-05).

The art style is pixel art (GDD-ART-01). Sprites are redrawn from this image by hand; the original stays untouched. Open item before the pixel art starts: Poncho's pronouns (GDD Open Question 5).
