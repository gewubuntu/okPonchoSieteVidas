# Poncho victory references

Shared by the user on 2026-11-08 ("Victory pose take the image as reference and the sprite."), as the reference for his victory
pose (GDD-ART-04, Open Question 35). Copies of the user's uploads. Do not edit or overwrite them.

- `victory.jpg`: the main one, a 100 x 100 pixel drawing (1024 px, 10.24 px a cell), front view: the taco raised high in his right
  paw (the viewer's left), his left paw a fist, the sombrero tilted. Read cell by cell into `scripts/art/poncho/victory-pixels.mjs`.
- `strip.jpg`: four frames at a coarser grid (about 8 px a cell): a ready stance with both fists up and no taco, then the taco
  raised higher in each frame, the last one stretched tall. The guide for the animation's order (`scripts/art/poncho/victory.mjs`).
